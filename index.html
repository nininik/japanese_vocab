☁️ 별표 동기화 설정 도움말

별표(★)를 구글 시트에 저장해서 여러 기기에서 같이 쓰는 방법입니다. 서버 가입 없이 구글 계정만 있으면 됩니다.

1. 구글 시트 만들기

  1. sheets.new에 접속해 새 시트를 만들고 이름을 정합니다. (예: japanese_vocab_stars)

2. Apps Script 붙여넣기

  1. 시트 메뉴에서 확장 프로그램 → Apps Script를 엽니다.
  2. 기존 코드를 모두 지우고, 이 창의 Code.gs 탭에서 복사한 코드를 붙여넣습니다.
  3. 저장(Ctrl+S)합니다.

3. 웹 앱으로 배포

  1. 오른쪽 위 배포 → 새 배포를 누르고, 톱니바퀴 아이콘에서 유형을 웹 앱으로 고릅니다.
  2. 다음 사용자로 실행: 나
  3. 액세스 권한이 있는 사용자: 모든 사용자
  4. 배포를 누르고 권한을 승인합니다. "확인되지 않은 앱" 경고가 나오면 고급 → (프로젝트 이름)(안전하지 않음)으로 이동을 누릅니다. 본인이 만든 스크립트라 정상입니다.
  5. 배포가 끝나면 나오는 https://script.google.com/macros/s/.../exec 형태의 웹 앱 URL을 복사합니다.

4. index.html에 URL 넣기

  1. index.html에서 아래 줄을 찾아 복사한 URL을 넣습니다.
    const SYNC_URL = '여기에 URL';
  2. 이 값이 비어 있으면 첫 화면의 동기화 박스가 숨겨집니다.

5. GitHub에 올리고 사용하기

  1. 수정한 index.html을 GitHub 저장소에 덮어씁니다. 1~2분 뒤 반영됩니다.
  2. 첫 화면의 별표 동기화 박스에 동기화 코드(영문/숫자 4~40자)를 입력하고 연결을 누릅니다.
  3. 다른 기기에서도 같은 코드를 입력하면 별표가 공유됩니다. 사람마다 다른 코드를 쓰면 별표가 섞이지 않습니다.

주의할 점

  • 코드를 수정했다면: 배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전으로 다시 배포해야 반영됩니다. URL은 그대로입니다.
  • 보안: 동기화 코드를 아는 사람은 그 코드의 별표를 읽고 바꿀 수 있습니다. 추측하기 어려운 문자열로 정하세요.
  • 동기화 실패 문구가 보이면 그 기기에는 저장됐지만 서버에는 올라가지 않은 것입니다. 연결을 확인한 뒤 다시 눌러 주세요.
이 도움말의 설정은 별표 동기화에만 필요합니다. 단어장 자체는 같은 폴더의 CSV 파일에서 자동으로 불러옵니다.
